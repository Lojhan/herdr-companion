# Herdr Companion app

Expo SDK 58 application for iPhone, Android and web. Uses Expo Router, React Native and a bundled xterm terminal renderer.

See the [project README](../../README.md) for installation, the local bridge, pairing, LAN access and tests. See [implementation status](../../docs/IMPLEMENTATION-STATUS.md) for supported features and remaining work.

From the repository root:

```sh
pnpm install --frozen-lockfile
pnpm dev:mobile
```

Start and pair the bridge as described in the project README before connecting to live workspaces.
